Installation

    IMPORTANT: If you have made changes to the script make a backup of the files, because they can be replaced.
    IMPORTANT: You must update from version 5.9. if you upgrade from another version will throw an error.
    IMPORTANT: Please follow the steps below strictly, otherwise the update will fail.
  • Login as Admin
  • Copy the file config > app.php from the folder Script to your current site
  • Copy the file bootstrap > cache > packages.php from the folder Script to your current site
  • Copy the following folder from the folder Script to your current site:
    • vendor (Full folder)

  • Unzip the file v6.0.zip and enter at URL https://yoursite.com/v6.0/ or if you have the script in subdirectory (subdomain) https://yoursite.com/test/v6.0/
    • IMPORTANT: You must be logged in as Admin

  • If all goes well, this message will appear, that's it! The new version has already been installed.
